# Как выложить сайт

Сайт живёт **в двух местах сразу**, и обновлять надо оба.

| Где | Адрес | Зачем |
|---|---|---|
| Свой сервер | https://sobez.mindandmotion.ru/ | Главный. Его видит ЮKassa, туда ведёт canonical, на него ссылаемся везде |
| GitHub Pages | https://bragingena1998.github.io/ | Зеркало. На него ведёт реклама |

**Почему зеркало нельзя выключить.** В единой перфоманс-кампании Директа
адрес сайта задан «объектом продвижения», и после создания кампании он
не меняется. Сменить его можно только новой кампанией — а это обнулит
накопленное обучение, ради которого кампания и крутится. Пока она живёт,
github должен отдавать ровно то же самое.

Редирект вместо копии не ставим: объявления ЕПК должны вести на домен
своего объекта продвижения, и переброс на чужой домен модерация может
не пропустить.

## Одна команда

Из папки `site`:

```
bash "Выложить сайт.sh" "что изменилось"
```

Она делает три вещи: кладёт страницы на сервер, отправляет их же в GitHub
и проверяет оба адреса. Если хоть один не ответил — скажет об этом.

## ⚠️ Проверять адрес, а не коммит

17.08 коммит лежал в GitHub правильный, а сайт отдавал сборку трёхчасовой
давности: **Pages не подхватил пуш.** Ни ошибки, ни признака — просто
старая страница.

Лечится пустым коммитом:

```
git commit --allow-empty -m "Пересборка страниц"
git push
```

Отсюда правило: **готовность проверяется запросом к адресу, а не выводом
`git log`.** Скрипт выше так и делает — надо смотреть его последние строки,
а не только «отправлено».

## Почему переехали со своего домена не сразу

17.08.2026 ЮKassa вернула анкету: «Ваш сайт не открывается — мы не можем
его проверить». Проверка с российского сервера показала, что `github.io`
открывается за 0,9 секунды и отдаёт 200. То есть дело было не в доступности.

Скорее всего, их проверка не принимает бесплатные хостинги, а в письмо
подставляет общую формулировку. Спорить об этом бессмысленно — быстрее
дать адрес на своём домене, который такого вопроса не вызывает.

## Что где лежит

- Исходники страниц — эта папка
- На сервере — `/var/www/sobez-site/`, отдаёт nginx напрямую
- Настройка nginx — `/etc/nginx/sites-available/sobez`

⚠️ Боту на том же домене принадлежат три пути: `/max` (вебхук MAX),
`/zayavka` (форма) и `/health`. Они перечислены в nginx поимённо, поэтому
новый файл на сайте их не перехватит. Не создавайте страниц с такими именами.

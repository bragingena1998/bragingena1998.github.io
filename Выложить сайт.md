# Как выложить сайт

Сайт живёт **в двух местах сразу**, и обновлять надо оба.

| Где | Адрес | Зачем |
|---|---|---|
| Свой сервер | https://sobez.mindandmotion.ru/ | Главный. Его видит ЮKassa, на него ведут все новые ссылки |
| GitHub Pages | https://bragingena1998.github.io/ | Зеркало. В рекламной кампании Директа прописан этот адрес, и поменять его в упрощённой кампании нельзя |

Когда кампания будет пересобрана на новый адрес, github можно выключить —
до тех пор он должен показывать ровно то же самое.

## Одна команда

Из папки `site`:

```
bash "Выложить сайт.sh" "что изменилось"
```

Она делает три вещи: кладёт страницы на сервер, отправляет их же в GitHub
и проверяет оба адреса. Если хоть один не ответил — скажет об этом.

## Почему переехали со своего домена не сразу

17.08.2026 ЮKassa вернула анкету: «Ваш сайт не открывается — мы не можем
его проверить». Проверка с российского сервера показала, что `github.io`
открывается за 0,9 секунды и отдаёт 200. То есть дело было не в доступности.

Скорее всего, их проверка не принимает бесплатные хостинги, а в письмо
подставляет общую формулировку. Спорить об этом бессмысленно — быстрее
дать адрес на своём домене, который такого вопроса не вызывает.

## Что где лежит

- Исходники страниц — эта папка
- На сервере — `/var/www/sobez-site/`, отдаёт nginx напрямую
- Настройка nginx — `/etc/nginx/sites-available/sobez`

⚠️ Боту на том же домене принадлежат три пути: `/max` (вебхук MAX),
`/zayavka` (форма) и `/health`. Они перечислены в nginx поимённо, поэтому
новый файл на сайте их не перехватит. Не создавайте страниц с такими именами.
